# 📚 Guia: Tecnologia Educacional Alinhada à BNCC

## A BNCC e a Cultura Digital

A Base Nacional Comum Curricular (BNCC) estabelece a **Cultura Digital** como uma das 10 competências gerais que todos os estudantes brasileiros devem desenvolver. Este guia mostra como implementar tecnologia de forma alinhada ao currículo.

---

## 🎯 Competência Geral 5 - Cultura Digital

> "Compreender, utilizar e criar tecnologias digitais de informação e comunicação de forma crítica, significativa, reflexiva e ética nas diversas práticas sociais, para se comunicar, acessar e disseminar informações, produzir conhecimentos, resolver problemas e exercer protagonismo e autoria na vida pessoal e coletiva."

### Desdobramentos:
1. **Compreender** - Entender como a tecnologia funciona
2. **Utilizar** - Usar ferramentas de forma produtiva
3. **Criar** - Produzir soluções tecnológicas
4. **Criticar** - Avaliar impactos e questões éticas
5. **Protagonizar** - Ser autor, não apenas consumidor

## 📅 Progressão por Ano/Série

### Anos Iniciais (1º ao 5º ano)

**Foco:** Letramento digital, lógica básica, criação simples

| Ano | Ferramentas | Projetos |
|-----|-------------|----------|
| 1º-2º | Tablets educativos, ScratchJr | Histórias animadas, jogos simples |
| 3º-4º | Scratch, Code.org | Jogos com variáveis, animações |
| 5º | Scratch avançado, planilhas | Projetos integrados, dados |

**Competências prioritárias:** CG2, CG4, CG5

---

### Anos Finais (6º ao 9º ano)

**Foco:** Programação, maker, projetos interdisciplinares

| Ano | Ferramentas | Projetos |
|-----|-------------|----------|
| 6º | Scratch, App Inventor | Apps simples, jogos temáticos |
| 7º | App Inventor, Arduino básico | Apps utilitários, eletrônica |
| 8º | Python básico, Arduino | Automação, análise de dados |
| 9º | Python, Web básico | Projetos integradores, portfólio |

**Competências prioritárias:** CG2, CG5, CG7, CG10

---

### Ensino Médio

**Foco:** Projetos complexos, pré-profissionalização, impacto social

| Série | Ferramentas | Projetos |
|-------|-------------|----------|
| 1ª | Python, banco de dados | Sistemas simples, análise de dados |
| 2ª | Web (HTML/CSS/JS) | Sites, apps web, UX |
| 3ª | Projeto integrador | Startup, pesquisa, portfólio |

**Competências prioritárias:** Todas, com ênfase em CG6, CG7, CG10

## 📊 Avaliação por Competências

### Rubrica de Cultura Digital (CG5)

| Nível | Descrição |
|-------|-----------|
| **Iniciante** | Usa tecnologia com ajuda; compreende comandos básicos |
| **Básico** | Usa ferramentas de forma independente; segue tutoriais |
| **Proficiente** | Cria soluções simples; adapta exemplos |
| **Avançado** | Desenvolve projetos originais; ensina colegas |

### Indicadores por Habilidade

**Compreender tecnologia:**
- [ ] Explica como funciona um algoritmo
- [ ] Identifica componentes de um sistema
- [ ] Relaciona tecnologia com impactos sociais

**Utilizar tecnologia:**
- [ ] Usa ferramentas adequadas para cada tarefa
- [ ] Resolve problemas técnicos simples
- [ ] Organiza arquivos e informações

**Criar com tecnologia:**
- [ ] Desenvolve programas funcionais
- [ ] Prototipa soluções para problemas reais
- [ ] Documenta e compartilha criações

**Criticar tecnologia:**
- [ ] Avalia fontes de informação
- [ ] Discute questões de privacidade
- [ ] Identifica vieses em algoritmos
